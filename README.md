# FluentWay — como publicar
1. Crie uma conta na Vercel e envie esta pasta (ou use o Vercel CLI: `vercel`).
2. Em Settings → Environment Variables, cadastre PAY_API_KEY (chave NOVA) e PAY_BASE_URL (veja .env.example).
3. No painel do provedor, aponte o webhook para https://SEU-DOMINIO/api/webhook.
4. Faça um pagamento de teste antes de divulgar.
